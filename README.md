# Wordcounter

Private, browser-only text statistics. Your text is never uploaded or saved.

Live: <https://wordcounter.marfeyx.ch>

## Development

```powershell
npm install
npm run dev
```

Open <http://127.0.0.1:5500>. This is a React/TypeScript app, so run it with
Vite rather than VS Code Live Server.
